# AWC 首次触发后的累计成交量

每个 condition 从 AWC 首次满足温度条件起，统计其 NO token 的逐笔成交，截止已保存 Gamma 元数据的 closedTime；缺少关闭时间或行情覆盖不足时，统计现有数据并标记 partial。后续天气过期和当地午夜不再截断。

- `daily.csv`：按温度市场所属日期汇总，不按实际成交日期分组。
- `cities.csv`：每日城市汇总。
- `conditions.csv`：每个温度档，含触发时间、关闭时间、首末笔成交时间及覆盖状态。
- `notional_pusd`：期间 NO 成交金额之和，未含费；`shares`：成交份数；`vwap`：成交额除以份数。
- `*_excluding_lowest`：剔除每城市每天最低温度档后的值。
- `eligible_*`：另按策略价格与收益条件筛选的成交；本批恰好与全部成交相同。

这是观察到的成交增量，符合“从信号成立到结束成交了多少”的口径。它包含重复换手和不同成交方向，不代表单个交易者能全部买到，也不等同于官方 YES/NO 合并的市场 volume 增量。仅计 NO，不把 YES 与 NO 直接相加。

本次读取 239 个小时文件，最新文件小时结束于 2026-10-25 11:00 UTC。2,244 个 condition 曾触发，其中 2,152 个具有从触发至保存关闭时间的连续小时文件覆盖，92 个缺少完整结束覆盖；另外 1,980 个未触发。连续小时文件不证明文件内部无丢包或末小时已写完。数据目录仍可能继续增加，因此与此前快照统计的数据截止范围不同。

天气时间使用 AWC receiptTime 代理，成交按源 timestamp 排序筛选，缺失时使用 timestamp_received。去重使用 token、transaction hash（无则 sequence）、时间、价格、数量及方向；缺少独立成交 ID，无法完全区分同交易内相同成交。该口径为粗略统计。
